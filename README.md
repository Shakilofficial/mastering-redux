# Todo App

This is a simple Todo application built with Vite, Tailwind CSS, and Redux.

## Features

- Add, toggle, and delete todos
- Filter todos by completion status
- Persist todos in local storage
- Responsive design with Tailwind CSS

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **Tailwind CSS**: A utility-first CSS framework for rapidly building custom designs.
- **Redux**: A predictable state container for JavaScript apps.
- **Redux DevTools Extension**: For debugging application state changes.

## Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Shakilofficial/mastering-redux.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd mastering-redux
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Start the development server:**

   ```bash
   npm run dev
   ```

## Usage

- **Add a Todo:** Type your task in the input field and press Enter.
- **Toggle Completion:** Click the checkbox to mark a task as completed or incomplete.
- **Delete a Todo:** Click the trash icon next to a task to delete it.
